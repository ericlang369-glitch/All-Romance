Blender 3D 热插拔模型规范（可选）
====================================

本应用已内置高质量 Three.js 程序化 3D 模型，开箱即用。
如未来你用 Blender 制作了更精细的写实 3D 模型，可将文件放入此目录并在 `src/config.ts` 的 `MODELS` 中启用对应文件名：

1. 第 02 幕 · 3D 干花标本框
   - 文件名：public/models/flower-frame.glb
   - 规范建议：
     * Draco 压缩后体积 < 3 MB
     * 模型中心对齐世界原点 (0, 0, 0)
     * 标本框正面朝向 +Z 轴
     * 总高度归一化约 2.4 世界单位
     * 可选命名节点：`Butterfly`（点击触发青碧微澜互动）

2. 第 03 幕 · 3D 封蜡信封
   - 文件名：public/models/wax-envelope.glb
   - 规范建议：
     * Draco 压缩后体积 < 2 MB
     * 模型中心对齐世界原点 (0, 0, 0)，正面朝向 +Z
     * 包含独立命名节点 `Flap`（上盖折叶，枢轴位于信封上沿）供点击火漆封蜡时驱动 3D 开合动画
     * 可选命名节点：`WaxSeal`（火漆蜡印点击热区）
